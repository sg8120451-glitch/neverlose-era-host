Deploy with HOKAS

Use your own HOKAS account to run this project in a separate HOKAS container.

  1. Download the project ZIP from the Servers panel.
  2. Open HOKAS and create your own Node.js server: HOKAS website.
  3. Upload the ZIP using the HOKAS file manager and extract it using the panel's supported file tools.
  4. Add your Discord bot token in HOKAS Settings → Environment Variables. Never put the token in your ZIP or share it with NEVERLOSE ERA.
  5. Use HOKAS's Command Builder to configure the correct Node.js start command for your entry file, save it, then run it.
  6. Check the HOKAS console for startup output and errors.

Free-plan limits: HOKAS currently lists 0.3 vCPU, 256 MB RAM, 512 MB disk and up to 3 servers per account. Free runtime uses an ad-based time allowance and is not guaranteed 24/7. HOKAS policy permits only one Discord bot per server.

Important: This is a manual external deployment guide, not a direct HOKAS API connection. Start/Stop/Restart and live logs inside NEVERLOSE ERA remain unavailable until HOKAS confirms an official integration API.
