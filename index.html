HELP CENTER

Frequently asked questions

Can I upload a JavaScript bot?

Yes. Select JavaScript / Node.js when uploading your ZIP.

Can I upload a Python bot?

Yes. Select Python when uploading your ZIP.

Will my bot start automatically after upload?

Not yet. Uploads are saved in private storage. A separate secure hosting runtime must be connected before bots can execute.

Are my uploaded ZIP files public?

The configured bot-uploads bucket is private. Access is controlled by your authenticated account and storage policies.

Are payments available?

Not yet. The plan cards are informational until a payment and subscription system is implemented.
